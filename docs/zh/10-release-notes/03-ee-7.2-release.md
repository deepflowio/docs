# v7.2.3 [2026/10/15]

## 业务观测

- 业务定义
  - Port 类型的服务定义支持按客户端资源或 IP 与客户端口识别业务服务，区分共享 IP、使用不同固定客户端口的服务，适用于包含客户端口的调用日志和流日志。
  - 云主机类型的服务定义支持独立配置客户端口、服务端口匹配，并支持多个端口。即使日志中 IP 为 `0.0.0.0`，也可通过同侧有效的云主机资源 ID 与端口识别业务服务。
- 业务告警
  - 支持在策略内创建自定义指标，基于已有指标的聚合和运算结果配置告警，并自定义指标别名与单位。
  - 支持按 `endpoint` 分组，分别计算指标并独立产生告警事件，覆盖秒级和分钟级数据。

## 应用观测

- 协议解析
  - 新增恒生 T2 协议解析，支持提取 UFX 功能号、业务字段、响应状态和追踪标识，解析明文及 LZO1X 压缩 Dataset，并聚合请求与应答生成调用日志。
  - 新增恒生 F2 协议解析，支持 UDP 多消息及协议分片重组，提取 UFX 业务字段与追踪标识，并支持请求应答聚合及报盘成功场景的特殊聚合。
- 调用链追踪
  - UDP 请求支持基于 `span_id` 和时间窗口进行调用链追踪及拓扑关联，并可与 TCP 调用和应用 Span 连接；关联信息不足时保留已确认的链路片段。
  - 支持使用 TOT（TCP Option Tracing）交换客户端、服务端的进程信息，绘制短连接场景下的进程拓扑。

## 代码观测

- 支持 CUDA 应用程序的内存申请量和内存使用量剖析，帮助定位 GPU 内存用量及内存泄漏问题。

## 告警管理

- 系统告警及新建自定义、业务告警的恢复条件默认不包含“无数据”，避免异常消失后因无数据而持续告警。升级时同步移除已有系统告警恢复条件中的“无数据”，已有自定义和业务告警保留原配置。
- 告警策略的监控频率和降噪窗口均增加 3 分钟选项，可分别配置检测周期与回溯数据范围。

## 系统管理

- Agent 支持运行于 Android 终端并提供 eBPF 能力，支持 ARM V8、Android AOSP 12 环境。
- 优化 Prometheus 数据存储与查询，直接存储指标名称和标签值，减少高基数标签引起的 Server 映射缓存内存增长。
- 统一普通管理员权限，可管理已加入组织内的团队、资源、业务对象及租户、普通管理员账号，并支持在已加入的组织间切换。
- 补充操作审计日志，统一记录成功操作的对象、动作和名称，批量删除按成功删除的对象分别留痕。
- 调整 V7 授权模块，业务观测拆分为业务解码、专用协议和业务建模三个独立模块，专属设备同步调整；应用内追踪、应用内剖析授权增加 Java 字节码增强能力，停用业务场景、业务系统的数量授权及对应扣费。
- 控制器列表支持按当前查询条件与数据权限导出完整 CSV 清单。
- 云平台区域白名单增加区域列表查询帮助及填写示例，便于查询云厂商区域名称并正确录入。

## 其他能力

- 聚合表格支持在滚动加载和分页切换加载间选择，可跟随组织设置或使用个人配置，支持调整每页数量、直接跳转页码及查看精确结果总数。
- 图表支持在完整纵轴范围和自动范围间切换，可通过个人设置指定默认模式，或在当前视图临时切换，便于观察成功率、响应率等指标的细微波动。
- 优化指标图表的查询区域展示，单区域图例仅显示指标名，多区域图例将区域名称置于指标名之后，表格图例使用独立的查询区域列。
- 已配置帮助文档映射的产品页面支持在弹窗内查看对应使用文档，保留目录和页面内导航，并支持放大、还原及加载失败后重试。

## 升级说明

- 业务服务客户端口匹配仅对包含客户端口的数据生效，指标表等缺少端口的数据仍沿用原匹配逻辑，服务归属可能与调用日志、流日志不同。
- Prometheus 升级后的数据写入并查询新 Sample 表，原表和历史数据保留且不迁移；本次新查询链路暂不支持查询升级前的历史 Prometheus 数据。
- 原业务追踪及业务场景、业务系统数量授权不自动转换为新的业务观测授权；升级后需根据已购功能重新申请并下发业务解码、专用协议、业务建模及对应专属设备授权。

# v7.2.2 [2026/09/10]

## 业务观测

- 交易监控
  - 新增交易监控工作台模式，聚合业务总览、业务拓扑、业务分析、交易监控告警、业务定义和业务解码等高频入口，并支持与全景观测模式自由切换。
  - 业务场景和系统拓扑的服务节点及路径新增业务详情，以交易口径展示核心指标和正常、响应异常、高时延、超时四类典型交易，并支持下钻调用日志、调用链及应用和网络分析。
- 观测范围
  - Kubernetes 流量采集支持按 Namespace 或 K8s Label 定义需要观测的业务 Pod 范围，并按团队和集群管理采集策略，在聚焦目标业务的同时减少大型集群中无关流量的采集与存储开销。
- 业务解码
  - 字段解码支持选择 WebSphere MQ 及 ISO 20022、CNAPS、JSNX SVC 三种内置业务协议，并通过 XML 路径提取业务字段。
  - WebSphere MQ Payload 支持识别 ISO 20022 和 CNAPS 金融业务报文，在保留 MQ 传输协议字段的同时提取业务协议、业务字段及业务响应码。
  - WebSphere MQ Payload 支持识别 JSNX SVC 业务服务总线报文，按 Service 和 process 拆分调用日志，并提取交易流水、服务、响应状态等业务字段。
  - JSON 字段提取路径支持固定数组下标，可精确提取多层嵌套数组中的业务字段。
  - 业务字段解析支持基于原生字段或已解析字段配置黑白名单前置条件，使同一业务字段可按交易场景选择不同的提取路径。
  - Attribute Tag 支持保留同名 Key 的多个 Value，并提供兼容原有取值行为的配置开关。

## 应用观测

- 协议解析
  - 新增 IBM WebSphere MQ 协议解析，支持 MQPUT、MQPUT_REPLY 和 ASYNC_MESSAGE 消息重组、同步与异步识别及调用日志生成。
  - 新增达梦数据库 SQL 协议解析，支持识别 SQL 请求、响应状态、错误码、影响行数及 Trace 信息。

## 告警管理

- 推送端点新增 TCP 推送，支持通过 Jinja 模板生成自定义文本或 XML 内容，并以原始 TCP 字节流发送至外部系统。

## 系统管理

- NPB 分发支持根据 deepflow-agent 的 CPU、内存和队列积压情况自动熔断与恢复，优先保障基础采集和控制面连接稳定。

## 其他能力

- 子视图派生指标明确展示当前时间与对比时间的区间或时点，优化环比、同比等对比数据的解释。
- 指标二级算子的四则运算支持交换数字与指标的位置，并支持输入正数、负数和小数。

# v7.2.1 [2026/08/27]

## 业务观测

- 全景拓扑
  - 全景拓扑拆分为场景、系统和自定义三个入口，原系统拓扑统一调整为自定义拓扑。
  - 系统拓扑支持按业务系统自动计算内部服务关系及外部一跳，并支持移动或复制为自定义拓扑。
  - 自定义拓扑画板增加常驻拖拽面板、框选、多对象移动、拷贝粘贴及右键快速添加能力。
  - 业务入口的观测点调整为独立的必填多选配置，并自动迁移存量配置，减少多采集位置造成的重复统计。
  - 无详情数据的物理节点不再支持点击下钻，并引导用户通过关联路径查看调用和性能详情。
- 分析
  - 业务观测增加分析模块，提供面向业务的调用列表，以及异常概览、趋势、排行、原因分析和异常明细。
  - 调用日志详情标签支持格式化预览，可自动识别 JSON、XML、嵌套 JSON、URL 编码、Header 键值对和普通文本。

## 应用观测

- 持续剖析
  - 支持自动采集和查询 Java CPU Profile，展示 JVM 方法调用路径及 CPU 热点。
- 易用性
  - 表格左侧快速过滤可配置自动实例和自动服务，并支持按客户端、服务端或双端筛选。

## 系统管理

- 新建管理员或租户账号时可同步选择所属组织与团队，账号列表增加组织和团队信息。
- 团队页面可见性支持管理二级页面下的三级 Tab 页卡。

# v7.2.0 [2026/08/13]

## 业务观测

- 业务总览
  - 全景拓扑业务总览支持按场景业务、系统业务分别创建和管理分组，并在业务墙与业务列表间共享分组配置。
  - 业务总览分组升级为团队内共享的 UGC 对象，并保留已有个人分组及归组关系。
  - 业务墙支持查看和切换指标数据源，显示对应时间精度，并在跨页面下钻时传递一致的绝对时间范围。
  - 业务墙趋势图根据查询时间范围自动选择展示粒度，使图表保持合理的柱子数量。
- 全景拓扑
  - 业务场景拓扑按单笔交易计算请求量、响应率和成功率，使节点及路径指标反映经过的交易笔数与最终处理结果。
  - 业务系统拓扑的客户端节点支持接入外部数据源，展示自定义指标、阈值状态和外部详情链接。
  - 场景拓扑变更搜索条件时支持预览新拓扑，并在已有 TraceID 关联时提供二次确认。
  - 拓扑服务节点和路径支持调试查询条件，确认后再应用到设置面板。
  - 业务场景服务节点支持修改资源类型，并与业务系统共享服务级资源类型配置。
  - 场景拓扑支持复制服务节点，复用节点配置且不复制已有连线关系。
- 业务解码
  - 字段解码策略和业务协议支持限定一个或多个业务服务，列表支持展示和过滤适用的业务系统与业务服务。
  - “自定义协议”更名为“业务协议”。
- 业务定义
  - 业务服务迁移至业务观测目录，并升级为“业务系统 → 业务服务”两层管理结构，支持分组树与列表视图、级联过滤、批量新建和存量服务平滑迁移。
  - 业务服务支持自定义 Key-Value 标签，可通过新建、编辑和 CSV 批量新建录入，并支持列表展示、导出和按标签搜索。
- 业务告警
  - 支持基线告警，可根据指标的历史变化规律和置信区间识别异常偏离，支持周期型与非周期型检测算法。
  - 告警事件按业务事件、自定义事件、系统事件分类展示，业务事件增加告警总数、Top 触发业务、Top 触发告警策略和触发告警指标概览。
  - 系统拓扑支持为多个服务或多条路径批量创建告警策略，并展示各对象的创建结果。
  - 告警策略按业务告警、自定义告警、系统告警分类展示，并支持导出 CSV。

## 应用观测

- 易用性
  - 调用链追踪、调用链拓扑、资源分析、路径分析、拓扑分析和调用日志支持按业务、服务、端点及业务字段搜索。
  - 调用链追踪支持按次启用或停用 `trace_id`、`syscall_id`、`tcp_seq_num`、`x_request_id`、`dns_request_id` 等追踪算法。
  - 调用链追踪的 Span 类型过滤器显示应用 Span、系统 Span 和网络 Span 的数量。

## 网络观测

- 易用性
  - 优化流日志详情及右滑框中的时序分析图，支持全景范围轴、框选缩放、特殊报文高亮以及趋势图与表格联动。

## 其他能力

- 搜索组件支持显示、匹配和查看最近执行的搜索条件。
- 左侧过滤支持按账号配置过滤项的显示、隐藏和排序。
- 优化搜索组件布局，容器搜索、应用搜索、进程搜索和业务搜索统一使用双行结构。

## 系统管理

- 超级管理员可在费用中心和授权管理中切换组织，跨组织查看和管理采集器、业务功能及授权信息。
